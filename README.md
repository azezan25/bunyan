# بنيان — حسابات البناء

تطبيق محلي لتسجيل عقود البناء والدفعات والمشتريات. لا يوجد حساب دخول أو API أو رفع للمستندات.
البيانات والمرفقات تُشفّر في متصفح الجهاز. الاستضافة توفّر ملفات التطبيق فقط.
قد تُنزّل قراءة الصور محرك OCR وملفات اللغة؛ لا تُرسل الصور إلى خادم.

## البناء

استخدم Node.js 22 أو أحدث ثم npm install وnpm run build.
الأمر يضبط BASE_PATH=/bunyan/ وPORT=4173 للبناء فقط، ويضع الموقع في docs/.
GitHub Pages ينشر main من /docs. ملف .nojekyll يحافظ على الملفات الثابتة.
بعد إعادة البناء، حدّث docs/. لا تضع بيانات أو مستندات أو نسخًا احتياطية في المستودع.

## الآيفون ونقل البيانات

1. قبل نقل أي بيانات من المعاينة: الإعدادات ← تصدير نسخة، واحفظ النسخة المشفّرة في تطبيق الملفات. احتفظ بكلمة مرور النسخة ومفتاح الاسترداد في مكان آمن خارج المستودع.
2. افتح رابط GitHub Pages في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
3. افتح بنيان من الأيقونة أولًا، ثم استعد النسخة هناك: الإعدادات ← اختيار ملف نسخة ← كلمة مرور النسخة ← استعادة. الاستعادة تستبدل البيانات الحالية.
4. تأكد من ظهور السجلات والمرفقات قبل حذف أي نسخة قديمة. التخزين محلي وقد يختلف بين Safari والتطبيق المثبّت أو يُحذف عند مسح بيانات الموقع؛ احتفظ بنسخ احتياطية.

لا تتوفر مزامنة بين الأجهزة. لا يُضمن استمرار أي خدمة استضافة مجانًا للأبد.
